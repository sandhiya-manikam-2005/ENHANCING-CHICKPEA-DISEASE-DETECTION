## 🚀 Quick Start (Step-by-Step from Scratch)

### Step 1 — Prerequisites

Make sure you have **Python 3.9+** installed.

```bash
python --version       # should print 3.9 or higher
```

### Step 2 — Clone / Download the project

Put the `chickpea-disease-detection/` folder somewhere on your computer, e.g. your Desktop.

```bash
cd ~/Desktop/chickpea-disease-detection
```

### Step 3 — Create a virtual environment

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### Step 4 — Install dependencies

```bash
pip install -r requirements.txt
```

> **GPU users (optional):** If you have an NVIDIA GPU, install the CUDA version of PyTorch first:
> ```bash
> pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
> ```
> Then install the rest: `pip install flask flask-cors pillow opencv-python numpy matplotlib seaborn scikit-learn`

### Step 5 — Generate the synthetic dataset

```bash
python backend/dataset_generator.py dataset 200
```

This creates 200 synthetic leaf images per class (Healthy, Blight, Rust, Wilt) split into train/val/test sets inside the `dataset/` folder.

> **Using real images?** See [Using Real Dataset](#using-a-real-dataset) below.

### Step 6 — Train the model

```bash
python backend/train.py \
  --data_dir dataset \
  --model_dir models \
  --epochs 50 \
  --batch_size 32 \
  --lr 0.001 \
  --patience 8
```

Training output example:
```
──────────────────────────────────────────────────────────
   Epoch  TrLoss  TrAcc  VaLoss  VaAcc         LR
──────────────────────────────────────────────────────────
       1  1.3821  27.68%  1.3745  28.12%  1.00e-03
```

After training, `models/best_model.pth` and `models/metrics.json` are saved, along with training curve and confusion matrix plots in `models/plots/`.

### Step 7 — Start the web application

```bash
python backend/app.py
```

Then open your browser at: **http://localhost:5000**

## 🧠 Model Architecture

```
Input Image (3 × 128 × 128)
         │
         ▼
┌─────────────────────┐
│   CNN Feature       │   Block 1: Conv2d(3→32)  + BN + ReLU + MaxPool
│   Extractor         │   Block 2: Conv2d(32→64) + BN + ReLU + MaxPool
│   (3 blocks)        │   Block 3: Conv2d(64→128)+ BN + ReLU + MaxPool
└─────────────────────┘
         │  (128, 16, 16)
         │  Reshape → (256, 128) sequential vectors
         ▼
┌─────────────────────┐
│  Bidirectional      │   LSTM(input=128, hidden=256, layers=2)
│  LSTM               │   Learns contextual & sequential dependencies
└─────────────────────┘
         │  h_forward ⊕ h_backward → (512,)
         ▼
┌─────────────────────┐
│  Fully Connected    │   FC(512→256) + Dropout(0.5)
│  + Softmax          │   FC(256→4)   + Softmax
└─────────────────────┘
         │
         ▼
  Disease Class (4 classes)
```

**Total parameters: ~2.8 million**

## 🔬 Preprocessing Pipeline (Algorithm 1)

| Step | Operation            | Formula / Method                     |
|------|----------------------|--------------------------------------|
| 1    | Image Acquisition    | Load high-res RGB leaf image          |
| 2    | Noise Removal        | Gaussian filter G(x,y)               |
| 3    | Contrast Enhancement | CLAHE on L-channel (LAB space)       |
| 4    | Segmentation         | Otsu's thresholding (maximise σ²_B)  |
| 5    | Normalization        | I_norm = (I − I_min)/(I_max − I_min) |

## 🌿 Disease Classes

| Class   | Description                                              | Color indicator      |
|---------|----------------------------------------------------------|----------------------|
| Healthy | No infection. Uniform green leaf.                        | Bright green         |
| Blight  | Ascochyta blight. Water-soaked tan/brown lesions.        | Brown spots, dark border |
| Rust    | Chickpea rust. Orange-brown pustules on surface.         | Orange pustules      |
| Wilt    | Fusarium wilt. Yellowing, browning, necrotic margins.    | Yellow-brown patches |

## 📊 Performance Metrics

The model is evaluated using:
- **Accuracy** = (TP + TN) / ALL
- **Precision** = TP / (TP + FP)
- **Recall** = TP / (TP + FN)
- **F1-Score** = 2 × (Precision × Recall) / (Precision + Recall)

Expected results with 200 images/class and 50 epochs:
| Metric    | Score  |
|-----------|--------|
| Accuracy  | ~90%   |
| Precision | ~89%   |
| Recall    | ~90%   |
| F1-Score  | ~89%   |

> Results improve significantly with real chickpea leaf images.

## 🖼 Using a Real Dataset

Replace the synthetic dataset with real chickpea leaf images. Organise them as:

```
dataset/
  train/
    Healthy/   ← put .jpg/.png images here
    Blight/
    Rust/
    Wilt/
  val/
    Healthy/  Blight/  Rust/  Wilt/
  test/
    Healthy/  Blight/  Rust/  Wilt/
```

Recommended free datasets:
- **PlantVillage** — https://www.kaggle.com/datasets/emmarex/plantdisease
- **Chickpea disease images** — search Kaggle / Roboflow for "chickpea disease"
- **CGIAR chickpea dataset** — https://data.cimmyt.org

Aim for at least **200 images per class** for good results (500+ is better).

## 🛠 Troubleshooting

| Problem | Solution |
|---|---|
| `ModuleNotFoundError: cv2` | `pip install opencv-python` |
| `CUDA out of memory` | Reduce `--batch_size` to 8 or 4 |
| `Cannot reach server` | Make sure `app.py` is running and use port 5000 |
| Low accuracy | Use more epochs, more data, or real images |
| Slow training | Use GPU or reduce image size to 64 |
| Port already in use | `PORT=5001 python backend/app.py` |
